# 한국 마케팅 (founder-marketing)

`founder/locale.json`의 `country`가 `KR`일 때 읽는다.

이 문서는 법률·세무 조언이 아니다. 지침과 플랫폼 정책은 개정된다. 현행 내용은 공식 페이지에서 확인하고, 필요하면 전문가에게 확인하라.

## 국내 채널

패널과 경쟁자 조사에서 첫 고객이 쓰는 곳을 골라 두세 개로 시작한다. 아래는 후보다.

| 채널 | 주소 | 비고 |
|---|---|---|
| 네이버 검색·블로그 | https://blog.naver.com | 검색으로 찾는 구매자가 많은 업종에 맞다 |
| 네이버 스마트플레이스 | https://smartplace.naver.com | 지도 검색 노출, 사진·메뉴·소식 관리 |
| 네이버 검색광고 | https://searchad.naver.com | 키워드 광고. 단가는 사이트에서 확인한다 |
| 카카오톡 채널 | https://business.kakao.com | 단골 알림, 문의 응대 |
| 카카오모먼트 | https://moment.kakao.com | 카카오 광고 |
| 당근 비즈니스 | https://business.daangn.com | 동네 기반 업종에 맞다 |
| 인스타그램, 유튜브 | 해당 서비스 | 시각 상품에 맞다 |
| 쿠팡·스마트스토어·배달앱 안의 광고 | 각 판매자 센터 | 플랫폼 안에서 노출을 사는 방식 |

광고 단가와 입찰가는 적지 않는다. 플랫폼에서 현재 값을 확인해 `founder/marketing.md`의 예산 표에 날짜와 함께 쓴다.

## 광고 표시 (추천·보증 심사지침)

- 광고주에게 대가(금전, 무료 제공, 협찬)를 받은 후기·추천은 경제적 이해관계를 소비자가 알 수 있게 표시해야 한다. 공정거래위원회의 "추천·보증 등에 관한 표시·광고 심사지침"이 다룬다. https://www.ftc.go.kr
- 표시 위치와 방식(글머리, 제목, 영상의 처음과 끝 등)은 개정된 적이 있다. 현행 지침을 읽고 따른다.
- 후기 작성을 조건으로 경품이나 무료 제공을 하는 이벤트도 표시 대상이 될 수 있다. 지침의 사례를 확인한다.
- 체험단·인플루언서와 일할 때 계약서에 표시 의무를 넣는다.
- 허위·과장 광고는 "표시·광고의 공정화에 관한 법률"로 규제된다. 건강기능식품, 의료, 금융처럼 업종별 광고 규제가 따로 있는 업종은 해당 기관의 기준을 확인한다.
- 가짜 후기, 가짜 팔로워, 패널 응답을 후기로 쓰는 일은 하지 않는다.
