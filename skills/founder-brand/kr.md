# 한국 브랜드 확인 (founder-brand)

`founder/locale.json`의 `country`가 `KR`일 때 읽는다.

이 문서는 법률·세무 조언이 아니다. 아래는 공개 검색으로 하는 사전 확인이다. 상표 등록 가능 여부는 변리사가 판단한다. 등록하기 전에는 아무것도 보호되지 않는다.

## 상표

1. KIPRIS https://www.kipris.or.kr 에서 상표를 검색한다. 후보 이름을 한글 표기와 영문 표기로 모두 넣고, 발음이 비슷한 이름도 찾는다.
2. 상품·서비스의 류(니스 분류)를 정한다. 같은 이름이라도 류가 다르면 결과가 다르다. KIPRIS의 상품류 검색으로 내 업종에 맞는 류를 찾는다. 카페는 음료·식품과 음식점업 류를 모두 본다.
3. 비슷한 상표가 보이면 외관, 발음, 뜻을 각각 비교해 후보에서 빼거나 변리사에게 묻는다.
4. 출원 절차와 수수료는 특허청 https://www.kipo.go.kr 에서 현재 값을 확인한다.
5. 사업자등록의 상호와 상표는 다르다. 상호로 등록했다고 상표권이 생기지 않는다.

KIPRIS Plus(https://plus.kipris.or.kr )는 Open API를 제공한다. 인증키 발급과 서비스별 활용신청이 필요하다. 이 스킬은 API를 호출하지 않고 검색 주소만 안내한다. API의 상표 검색 이용 조건은 아직 확인하지 않았다.

## 도메인

- `.kr`, `.co.kr` 도메인이 비어 있는지 한국인터넷진흥원(KISA, https://www.kisa.or.kr )의 도메인 조회 서비스 후이즈 https://whois.kr 에서 확인한다. 등록은 등록대행 사업자를 통해 한다.
- `.com` 도메인도 함께 확인한다.

## 국내 플랫폼 이름

가게나 서비스 이름이 아래에서 이미 쓰이는지 직접 검색한다. 같은 이름이 있으면 구분하기 어렵다.

| 어디서 | 주소 | 확인할 것 |
|---|---|---|
| 네이버 블로그 | https://blog.naver.com | 블로그 아이디, 같은 이름의 인기 블로그 |
| 네이버 스마트플레이스 | https://smartplace.naver.com | 같은 이름의 업체 등록, 지도 검색 결과 |
| 카카오톡 채널 | https://business.kakao.com | 채널 이름과 검색용 아이디 |
| 네이버 지도, 카카오맵 | https://map.naver.com , https://map.kakao.com | 같은 이름, 비슷한 이름의 가게 |
| 인스타그램, 유튜브 등 | 해당 서비스 | 핸들 |

## 읽기 쉬운 이름

한글로 읽고 말했을 때 발음이 분명한지, 받아쓰기 쉬운지, 영문 표기가 여러 가지로 읽히지 않는지 확인한다. 간판과 앱 아이콘에서 한글과 영문 모두 읽히는지 본다.
