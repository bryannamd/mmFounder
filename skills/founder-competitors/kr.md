# 한국 경쟁자 조사 (founder-competitors)

`founder/locale.json`의 `country`가 `KR`일 때 읽는다.

이 문서는 법률·세무 조언이 아니다. 사이트 약관과 화면 구성은 바뀐다. 현재 이용 조건은 각 사이트에서 확인하라.

## 지도·리뷰 출처

| 출처 | 주소 | 얻는 것 |
|---|---|---|
| 네이버 지도(플레이스) | https://map.naver.com | 가게 위치, 메뉴·가격, 영업시간, 방문자 리뷰, 블로그 리뷰 |
| 카카오맵 | https://map.kakao.com | 가게 위치, 평점, 후기, 영업시간 |

- 두 지도의 평점 방식이 다르다. 평점 체계(별점인지 키워드인지)를 `rating` 칸에 쓰기 전에 확인하고 `positioning_line` 옆 메모에 적는다.
- 협찬·체험단 표시가 있는 글은 일반 후기와 구분한다. 불만 주제를 셀 때 협찬 글을 뺀다.
- `location_or_channel`에는 플레이스 또는 카카오맵 가게 주소(URL)를 적는다.
- 지도 화면을 대량으로 내려받지 않는다. 사람이 읽는 방식으로 읽고, 인용은 짧게 원문 그대로 쓴다.

## 상권과 점포 수

- 소상공인365 빅데이터 상권분석: https://bigdata.sbiz.or.kr 에서 업종별 점포 수와 개폐업을 본다. 매출은 추정치다.
- 프랜차이즈 경쟁자: 공정위 가맹사업거래 정보공개서 https://franchise.ftc.go.kr 에서 점포 수와 가맹 조건을 본다. 평균매출은 실제보다 높게 적힌 사례가 보도된 적이 있다. 경쟁자의 매출 상한으로만 쓴다.
- 배달앱 가격은 매장 가격과 다를 수 있다. 어느 쪽 가격인지 `price_of_comparable_item`에 적는다.

## 온라인 경쟁자

스마트스토어, 쿠팡, 앱스토어·구글 플레이 리뷰도 같은 방식으로 읽는다. 리뷰 수와 평점, 최근 리뷰 날짜를 `source_date`와 함께 기록한다.
